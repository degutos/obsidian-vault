

When using vim if you want to search something with case insensitive, use:

```sh 
/word\c # search for word or WORD 
```


### Set number line

```sh
:set nu # show line number
:set nonu # hide line number, remove
:set rnu # show relative line number
:set nornu # show not a relative number line
:set relativenumber # same to show relatively line numbers
:set norelativenumber # same to not show relative line number 
```
